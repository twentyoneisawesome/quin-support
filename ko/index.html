Landy Money 지원 센터

오프라인 우선 가계부 앱 —— 데이터는 내 기기에 저장되며, 백업 여부는 직접 정합니다.

Landy Money 소개

Landy Money는 모든 처리를 기기에서 수행하는 개인 가계부 앱입니다. 가입도 로그인도 필요 없이 —— 앱을 열면 바로 계좌, 거래, 예산, 투자를 기록할 수 있습니다. 재무 데이터는 기기에 저장되며 어떤 온라인 계정과도 연결되지 않습니다.

자주 묻는 질문

내 데이터는 어디에 저장되나요?

모든 재무 데이터는 기기 내부의 로컬 데이터베이스에 저장됩니다. Landy Money는 오프라인 우선으로 설계되어 계정이 필요 없으며, 기록이 어떤 로그인과도 연결되지 않습니다.

계정 가입이나 로그인이 필요한가요?

필요 없습니다. Landy Money에는 계정도 로그인도 없습니다. 앱을 여는 순간부터 모든 기능을 사용할 수 있습니다.

데이터를 백업하거나 다른 기기로 옮길 수 있나요?

네, 수동 클라우드 백업으로 가능합니다. 설정 → 데이터에서 iCloud에 백업(iPhone) 또는 Google Drive에 백업(Android, Google 로그인이 필요합니다)을 누르세요. 새 기기에서는 같은 Apple ID 또는 Google 계정으로 로그인하고 Landy Money를 설치한 뒤 iCloud에서 복원 / Google Drive에서 복원을 누르면 됩니다. 참고: 백업은 버튼을 누를 때에만 만들어지고 매번 이전 백업을 덮어씁니다. 첨부한 사진은 포함되지 않습니다. 복원하면 앱에 있는 현재 데이터가 모두 대체됩니다. iPhone은 iCloud, Android는 Google Drive를 사용하므로 두 플랫폼 간에는 백업을 옮길 수 없습니다. 자동 동기화는 없고 앱을 삭제하면 해당 기기의 데이터도 함께 삭제되므로, 먼저 백업해 두십시오. 거래를 Excel이나 Numbers에서 쓰고 싶을 뿐이라면 거래 내역 내보내기 (CSV)를 이용할 수 있지만, CSV는 앱으로 다시 가져올 수 없습니다.

Landy Money는 인터넷에 연결되나요?

핵심 기능은 완전히 오프라인으로 작동합니다. 일부 선택 기능은 인터넷을 사용합니다: 실시간 환율, 대만(TWSE) 주가, 전자 인보이스 동기화(대만 지역의 유료 기능), 구독 관리입니다. 자세한 내용은 개인정보 처리방침을 참고하세요.

버그를 발견했거나 궁금한 점이 있으면 어떻게 하나요?

언제든지 알려 주세요. 이메일로 연락 주시면 최대한 빨리 답변드리겠습니다.

문의하기

질문, 의견, 버그 신고 모두 언제나 환영합니다.
